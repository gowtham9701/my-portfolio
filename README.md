# my-portfolio — Gowtham Kumar

A responsive, cinematic portfolio for Nayudu Venkata Gowtham Kumar, built from scratch with semantic HTML, CSS, and vanilla JavaScript. It uses an original dark editorial design and does not reuse source code from the unlicensed reference repository.

GitHub profile: <https://github.com/gowtham9701>

## Run locally

No package install or build step is required. From this directory, run:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

You can also open `index.html` directly. A local server is recommended for the resume download and browser PDF viewer.

## Customize

- Update the portfolio content in `index.html`.
- Replace `assets/gowtham-portrait.png` with a portrait using the same filename, or update the image source in `index.html`.
- Replace `assets/Venkata_Gowtham_Kumar_Nayudu_Resume.pdf` to update the downloadable resume.
- Adjust the visual system and responsive layouts in `styles.css`.
- The mobile navigation and reveal-on-scroll behavior are in `script.js`.

## Deployment

This is a static site and can be hosted on GitHub Pages, Vercel, Netlify, or any static web host. Keep the HTML file and `assets/` folder at the site root.
